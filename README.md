> **Free, royalty-free, public-domain audio library for sleep, relaxation, meditation, focus, and background ambiance.**

A curated collection of seamless looping soundscapes (rain, crackling fireplace, night crickets, ocean surf), frequency-tuned binaural brainwaves (Delta for deep sleep, Theta for REM), and calm sleeping music. All files are cleanly named in kebab-case, strictly organized into category folders, and ready for use in web apps, mobile apps, Discord bots, games, or offline sleep players.

## 🚀 Quick Start & Usage

### 1. Clone the Repository
```bash
git clone https://github.com/localhostnick/-open-sleep-sounds.git
cd open-sleep-sounds
```

### 2. Stream Directly via Raw GitHub CDN
You can stream any audio file directly inside web apps or mobile players using the raw GitHub URL:
```html
<audio controls loop src="https://raw.githubusercontent.com/localhostnick/-open-sleep-sounds/main/sounds/01-rain-and-storms/heavy-rain.mp3"></audio>
```

### 3. Programmatic Access (`catalog.json`)
Inspect `catalog.json` for full track metadata, relative paths, tags, and category IDs in your JavaScript, Python, or Flutter applications:
```javascript
fetch('https://raw.githubusercontent.com/localhostnick/-open-sleep-sounds/main/catalog.json')
  .then(res => res.json())
  .then(catalog => {
    console.log(`Loaded ${catalog.categories.length} sound categories!`);
  });
```
